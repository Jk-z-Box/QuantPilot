# QuantPilot

**可自行部署的永續合約研究與交易管理工作台，優先使用模擬盤。**

[English](README.md) · [部署說明](docs/DEPLOYMENT.md) · [0.15.0 更新](docs/V0150.md) · [文件索引](docs/README.md)

目前版本 **0.15.0**，最新程式位於 **main 主分支**。真實交易預設關閉。

## 主要功能

- 搜尋 Binance、OKX、Gate 已上市的 USDT 本位與幣本位反向永續合約；各結算錢包獨立記帳。
- 交易所 → 伺服器 → 網頁以 WebSocket 推送行情、資金與倉位，包含斷線重連、REST 補讀與 SSE 降級。毫秒時間戳不代表交易所每毫秒更新。
- 依已收盤的週線、日線、4H、1H，以及 EMA、RSI、MACD、ATR、成交量、資金費率、OI 和外部證據評分；有效分數、參數、權重與開關可調整。
- 多個模擬、測試及真實帳戶；每個交易對獨立設定幣數、槓桿、逐倉／全倉、系統評估倉位與加倉預算。
- 帳戶獨立資金限額、逐項開關與明細；可選 AI 額度管理，在明確授權範圍內評估並應用，修改前自動備份。
- 固定與分批止盈止損，新增可選的浮虧加倉評估、移動止盈；新增風險仍須通過資金、強平距離和授權檢查。
- 可選 OpenAI API 或伺服器 Codex 登入：交易前審核、持倉評估、來源核驗、策略復盤和版本備份。
- Telegram 分類提醒、網頁音效及音量、Linux 一鍵安裝、CLI 管理和網頁更新。

## 安裝與開始使用

需要 Linux / systemd、Python 3.11+、venv、curl、tar。下列指令先將 main 解析為固定提交，再安裝該版本；端口、帳號可自訂，密碼於終端隱藏輸入，不需要 GitHub Token。

```bash
QP_REF=$(curl --proto '=https' --tlsv1.2 -fsSL https://api.github.com/repos/Jk-z-Box/QuantPilot/commits/main | python3 -c 'import json,sys; print(json.load(sys.stdin)["sha"])') && curl --proto '=https' --tlsv1.2 -fsSL "https://raw.githubusercontent.com/Jk-z-Box/QuantPilot/$QP_REF/install.sh" -o /tmp/quantpilot-install.sh && sudo bash /tmp/quantpilot-install.sh --ref "$QP_REF"
```

既有安裝在最後加上 `--upgrade`。域名、TLS 和 Cloudflare Origin Rules 請依[部署說明](docs/DEPLOYMENT.md)設定。

1. **市場與機會**：選擇交易對與週期，查看有效性、阻擋原因與來源。透過「調整排序」拖曳或上下移動監測卡片。
2. **帳戶與倉位**：先使用模擬帳戶，啟用指定交易對並設定倉位；在帳戶設定調整資金限額及 AI 可修改範圍，再儲存。手動「評估並應用」可在自動額度管理關閉時使用，詳見 [0.15.0 說明](docs/V0150.md)。
3. **浮虧加倉／移動止盈**：在「帳戶設定 → 各交易對 → 數量、保證金、槓桿與加倉」中獨立開啟。兩者預設關閉，詳細條件見[本版說明](docs/V0140.md)。
4. **恐懼與貪婪指數**：在「量化邏輯」開啟指標，調整權重、極端值與缺失處理。資料來自 [Alternative.me](https://alternative.me/crypto/fear-and-greed-index/)，是每日 BTC 市場參考，不是各幣或股票的專屬指數。
5. **提示音**：在「設定 → 交易與機會提醒」選擇「柔和長鈴」或「自訂提醒 · y1462」，調整音量，點「啟用／測試聲音」後儲存。手機鎖屏或關閉網頁可能停止聲音。
6. **量化邏輯**：停用參數即不參與評估，不恢復預設值。變更前自動備份，可匯出、匯入及設定保留數量。

刷新會保留目前分頁、交易對與 K 線週期；帳戶設定若已被其他頁面修改，會提示衝突，不再靜默覆蓋。

## 使用邊界

預設監測 BTC、ETH、SOL、AVGO、SOXL，但交易所必須實際提供該合約。公開資料缺失或過期會明確顯示；AI 不會補造資金流、價格或清算熱力圖。

模擬盤使用統一費率、滑點與保證金估算，並非完整複製交易所。**本地測試不等於實盤認證**；真實執行仍需伺服器開關及綁定憑據與版本的認證，見[執行驗收](docs/ACCEPTANCE.md)。AI 不可用時，需審核的開倉／加倉暫停，既有保護退出繼續。

移動止盈由伺服器執行；斷網時交易所原生止損仍保留，但移動止盈可能無法觸發。價格跳空、手續費和滑點可能影響實際收益，不保證獲利。

0.14.0 已移除早期現貨控制台與專屬資料；升級前自動備份，保留現有帳戶、倉位、交易紀錄、策略、密鑰與登入設定。更新後自動交易預設暫停，確認狀態後再啟用。

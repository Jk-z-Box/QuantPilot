# QuantPilot 0.11.0：实时账户资金

在「账户与仓位 → 账户设置 → 交易所资金实时状态」中开启 **WebSocket 实时更新（只读）**。新增和已有的交易所账户默认开启。保存 API 密钥后自动建立连接，不需要启用自动交易，也不需要打开实盘下单总开关。

## 更新方式

- Gate、OKX、币安 USDT 合约账户订阅资金、持仓、订单事件。服务器收到变化立即推送到当前登录的网页，不等待页面定时刷新。
- 资金和订单事件触发完整资金核对；短时间内的事件合并，完整读取最多每秒一次。没有事件时每 60 秒进行一次兜底核对。首次连接需要加载交易所市场资料、读取账户并确认私有订阅，可能需要几十秒。
- 有持仓时订阅标记价格，权益及浮动盈亏随价格变化进行显示估算，并明确注明来源；可用资金始终采用交易所完整接口返回值。标记价格更新也会触发限速后的完整核对。
- Gate 经典合约账户的钱包 `total` 不包含未实现盈亏；界面权益采用钱包余额加交易所 `unrealised_pnl`。OKX 使用 USDT `eq/upl/availEq`，币安使用 USDT `walletBalance/unrealizedProfit/availableBalance`。展示范围为 USDT，不代表其他币种或整个多资产账户的总权益。Gate 统一账户的合约接口不提供完整 USDT 权益，因此显示未知并提示，不套用经典账户公式。
- 模拟账户继续使用本地模拟账本。真实交易的资金和强平检查仍使用完整账户读取，不使用网页的标记价估算数据。

## 状态与故障

卡片会显示「正在连接」「实时已连接」「重连中 · 旧数据待核对」「实时更新已关闭」等状态，并显示最近完整资金核对时间。无交易或资金变化时，连接心跳正常即可维持实时状态。首次 REST 成功不会被误报为订阅成功。

断线自动重试；重连必须重新读取完整账户。私有连接或网页推送中断时，保留旧值并明确标注待核对。可检查交易所 API 的合约读取权限、IP 白名单、环境和网络；无需提款权限。仍可使用「读取与核对」手动读取。

页面通过登录会话保护的 SSE 接收更新；退出登录、修改密码或会话过期会结束推送。Nginx 遵循 `X-Accel-Buffering: no`，现有 Cloudflare Origin Rules 与 HTTPS 部署无需改端口。不要在自建代理上缓冲 `/api/v2/account-events`。

## 边界

“实时”是事件驱动，仍取决于交易所推送频率和网络延迟；完整资金字段的补读可能晚于标记价格估算。只读连接不接管外部持仓、不改变杠杆、不创建或取消订单，也不解除执行异常锁定。升级保留配置和资金记录，自动开仓按现有启动规则暂停。

# 安全边界

## 当前保护

- 真实下单未实现，适配器仅暴露公共行情和只读余额方法。`live_enabled=true` 或非 false 的 `QP_LIVE_ENABLED` 导致启动失败；订单 `mode=live` 在网络调用前拒绝。
- 密码使用随机盐 scrypt；不提供默认生产密码。配置、账本和主密钥位于私有目录。
- 随机会话令牌只以绑定密码哈希的摘要存库；8 小时到期，最多保留 20 个会话。退出和改密立即撤销旧凭据对应会话。
- 登录限速存储于数据库，避免重启清除计数。默认每来源 15 分钟最多 10 次失败，全局最多 100 次。
- 写请求校验精确 Origin、JSON 内容类型、正文大小和 CSRF token。所有业务 API 需要会话。域名受允许列表限制，未开放 CORS。
- 远程来源要求 HTTPS，Cookie 使用 HttpOnly/SameSite=Strict，并在 HTTPS 模式启用 Secure。禁用 API 文档公开页，返回 no-store、CSP 和防嵌入头。
- 交易所/OpenAI 凭据使用 Fernet 加密，只在服务器进程内解密，不通过读取 API 回显。请求验证错误不会返回原始敏感输入，交易所异常不会直接写入日志。
- AI 只接收模拟资产汇总和公共指标；没有下单工具，不改变权限，不能解除实盘锁。响应拒绝、未完成、非法结构或网络错误均失败关闭。

本机管理员、root 或同时持有数据库与主密钥的人能够读取凭据。应用层加密不防止主机被入侵。备份同样属于秘密材料。

## 操作限制

这是单管理员、现货、模拟盘的研究版本。未实现 MFA、RBAC、外部不可篡改审计、自动备份保留、账户资金对账或灾备切换。审计存于本地数据库，可被主机管理员修改，不称为不可篡改审计。

策略使用示例参数，不承诺收益。日损失限额不能保证最大亏损，尤其在断网、跳空、停机或报价异常时。暂停开仓不自动平仓，保护卖出依赖可用行情与服务持续运行。

## 未来实盘放行门槛

**当前版本不能通过勾选开关启用实盘。** 必须增加独立执行组件并完成下列工作后，再开展明确授权的实盘验收：

1. 先在各交易所测试环境逐个认证，区分现货/合约、测试环境/生产环境；验证账户权限、IP 白名单与禁提币权限。
2. 持久化订单意图、客户端订单 ID、提交/部分成交/取消/拒绝状态；断线和超时时进入未知状态并对账，不能盲目重试创建订单。
3. 交易所余额/仓位/开放订单权威对账，处理部分成交、手续费币种、精度、最小金额、盘口深度、限频、时钟同步与撮合异常。
4. 建立独立配置开关、部署开关、限时人工解锁和订单审批；重启自动撤销解锁，AI 无解锁权限。
5. 实现原生保护单或经过验证的替代方案，测试异常撤单、网络分区、进程崩溃、重启恢复、跨日风控及故障时的人工退出。
6. 独立代码安全审查、全部关键分支测试、交易所测试环境集成验收与长时间模拟观测。
7. 在用户明确选择账户、交易所、品种、金额与风险限额后，才开始小额分阶段实盘验收；不能因单元测试通过自动升级。

上述检查未完成前，本项目保持没有真实订单网络通道的状态。

## 已泄露的 GitHub 凭据

聊天中出现的凭据不保存在本项目。本次发布经用户再次明确授权，仅在进程内存中临时用于 GitHub API，未写入仓库、文件、Git 配置或输出。应在 GitHub Settings → Developer settings → Personal access tokens 撤销对应凭据，并检查近期授权活动。后续只使用 GitHub 安全连接、正常 OAuth 或 SSH。

# 安全边界（0.2）

- 默认本地模拟。新增交易所执行通道有环境开关、限时验收、账户启用、品种授权等多层限制，详见 [验收门槛](ACCEPTANCE.md)。本次没有真实下单或交易所测试网验收。
- 密码随机盐 scrypt；无默认生产密码。会话摘要绑定密码版本，退出/改密撤销会话，最多 20 会话，8 小时过期。登录失败限制持久化。
- 业务接口需要登录；写入校验精确 Origin、JSON、正文大小和 CSRF。敏感验证错误不回显原始输入。
- 远程访问要求 HTTPS；Cookie HttpOnly、SameSite=Strict，HTTPS 模式 Secure。固定 Host、无跨域放行、no-store、CSP、防嵌入。
- 每个账户独立加密凭据，读取接口只返回配置状态。Fernet 主密钥和数据库都在私有目录；同时持有两者的管理员可解密。备份包含解密材料，必须私下保管。
- AI 仅接收筛选后的行情/事件及匿名化资金和持仓，新闻等输入作为不可信数据处理；没有工具调用能力。严格结构校验、至少 60 秒间隔、只允许有限评分修正和收紧风险；不能解除账户门槛或绕过订单检查。
- 未知订单不重试，账户故障锁定持久化。交易所模式仅允许逐仓、单向、USDT 线性永续；外部持仓不自动接管。
- 暂停新仓和停用自动交易仍执行已有模拟保护；重启默认暂停各账户新交易。模拟保护依赖可验证行情，交易所原生保护需实际联调证明。

这是单管理员、单进程应用。没有 MFA、多人权限、不可篡改审计或自动灾备；本地管理员可修改审计与验收记录。日损失/止损预算不保证实际最大损失，跳空、断网和交易所错误仍会影响执行。

不把交易所提款权限交给本应用。不在聊天、仓库或日志保存任何 API Secret、Token 或密码。历史聊天中出现的 GitHub 凭据应撤销；优先使用 GitHub 安全连接。若连接写入权限不足且用户明确授权临时凭据，凭据仅在进程内存中使用，不写入文件、环境变量或日志。

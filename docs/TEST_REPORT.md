## 核心回归用例

- 精确现金/费用/成本/盈亏记账、部分与全部减仓、禁止负仓位。
- 重复请求及重启后的幂等；同一编号不同内容冲突；12 个并发相同请求只记账一次。
- 多个并发买单共享风控预算，不超限开仓。
- NaN/Infinity/负数/零数量/精度异常/过期订单拒绝。
- 过旧、未来、无时间戳、异常价差、缺失估值时失败关闭。
- 开仓限额、组合敞口、单仓金额、日损失、预计止损损失及费用后的余额验证。
- 暂停开仓期间允许减仓；跳空按当前盘口退出；保护卖出不受开仓金额上限阻挡。
- 一个市场断线时其他市场仍能执行保护退出。
- 策略停用/版本变化禁止旧任务开仓；自动策略重启后停用；同根 K 线不重复提交。
- 登录限速、注销/过期/改密撤销、Origin、CSRF、Host、正文类型和大小保护。
- 错误响应不回显秘密，凭据加密、备份恢复、丢失主密钥时拒绝生成替代密钥。
- AI 严格结构、拒绝/未完成/非法响应、输入最小化、无工具和无订单权限。
- Web 与 CLI 的配置更新使用同一写锁，不会覆盖新密码。

## 自审修复

1. 改密后的旧进程仍可能接受旧密码：改为每次鉴权读取当前密码配置，并将会话摘要绑定密码版本。
2. 修改 AI 设置与 CLI 改密可能覆盖对方写入：增加同一配置文件锁与读改写合并。
3. 保护卖出不应依赖其他市场估值：买入校验组合估值，减仓仅校验目标市场，逐市场隔离故障。
4. 重复策略 tick 可能产生同编号、不同到期时间的冲突：提交前查询已持久化的 K 线订单。
5. 数据库存在凭据但主密钥丢失：启动失败并要求恢复原密钥，禁止静默换钥。
6. 校验异常可能包含密码或 API Key：覆盖默认验证错误响应，不返回原输入。
7. 依赖锁初次遗漏传递 extras：补齐解析并在干净环境实际验证哈希安装。

这是一轮实现者自审，不等同于独立安全审计。

# 0.14.0 · Workspace reliability and position automation / 工作台與持倉自動化

## Workspace / 工作台

- Session-first startup hides the login form until authentication is known. A network error shows retry rather than pretending the session expired. Page, instrument and timeframe survive refresh within the tab.
- Account updates carry a revision; a concurrent edit returns HTTP 409. Paused accounts save normally, including strategy-change rechecks.
- Monitor display order is stored separately from trading inputs; dragging or arrow buttons changes presentation only.
- Added the selected warm chime and uploaded `y1462.wav` as independent choices. Volume remains adjustable. Browser audio requires a user gesture after loading.
- 啟動先確認登入狀態，避免登入頁閃現；刷新保留頁面。帳戶採版本衝突檢查，暫停時同樣可儲存。監測排序與交易邏輯獨立。

## Loss additions / 浮虧加倉

Opt in per account and pair. The adverse **underlying price** move must be within the configured trigger and maximum percentage, with a cooldown since entry or the last addition. It is not leveraged ROE.

A fresh, valid same-direction opportunity, the strategy addition switch, extra score requirement, shared addition count/ratios, quantity cap, risk and liquidation checks, enabled account/pair and optional AI approval still apply. Loss additions are an explicit exception to the ordinary “profitable additions only” setting. Turning off that ordinary strategy condition removes that condition; it does not silently reset its default. Reaching the maximum loss or cooldown boundary does not itself place an order.

逐帳戶、逐交易對開啟。浮虧只觸發評估，仍須有效同向機會與完整風控通過。與普通加倉共用次數、初始數量比例及風險額度；最多加倉填 0 時仍禁止加倉。已分批止盈後不再浮虧加倉。

## Trailing take profit / 移動止盈

Opt in per pair, set favorable-price activation, percent or 1H ATR retracement distance, and the fraction of **remaining** quantity to close. The favorable high/low and tightened trigger are durable across restarts. The trigger never loosens and a confirmed trailing partial exit occurs once per position. The remaining position keeps its fixed targets and stop.

New lines require at least a 0.3% favorable gap from average entry as a simple fee/slippage allowance, not a promise of net profit. Missing or expired ATR prevents a new ATR line while retaining the previous line. Stale quotes cannot trigger a simulated fill. Protection continues when opening automation is paused. AI timeout uses the protective-exit fallback. Execution is server-side; native exchange stops remain independent.

可設定啟動漲跌幅、百分比／ATR 回撤距離與平倉比例。最高／最低有利價及保護線持久保存；只收緊不放寬，分批移動止盈只執行一次。觸發不保證成交價，亦不保證盈利；網路中斷時保留交易所原生保護。

## Fear & Greed / 恐懼與貪婪

Source: [Alternative.me](https://alternative.me/crypto/fear-and-greed-index/). Daily BTC index, 0–100; fetch cache one hour, stale after 36 hours from actual publication. Attribution and history are visible. Optional weight, fear/greed thresholds, contrarian or trend-following interpretation, adverse-direction block and missing-data block. Disabled by default; excluded for equities. The value is never inferred by AI.

每日 BTC 市場指數，不代表 ETH、SOL、AVGO 或 SOXL 的個別情緒。關閉指標即不計分；來源缺失／過期不會被當成有效數值。

## Upgrade / 升級

The v1 spot UI, endpoints, executor and advisor are removed. A consistent private backup precedes deletion of only v1 keys (`account`, `strategy`, `last_advice`), v1 orders and v1 credentials. Current v2 data, audit, sessions, global pause and credentials are retained. Backups remain available for rollback and are not published. Main is now the web updater's source.

舊版程式與專屬資料已清理，現有工作台資料保留。舊資料備份留在伺服器私有備份目錄；更新來源改為 main。新風控功能不會自動替使用者開啟。
